## 1. 분석 배경 및 목표

* ‘thumbsup’의 주요 기능인 **투표 참여 증대**를 출발점으로, 서비스 내 사용자 경험을 개선해 장기적으로 수익 향상 도모
* **문제 현황**:

  * 2023년 5월 이후 투표 건수 급락
  * 투표 감소와 함께 포인트 사용액/횟수도 지속 감소
  * 투표 참여율 ↔ 포인트 사용 상관계수 **0.72**

## 3. 문제점

### (1) 유저 이탈 문제

* 전체 탈퇴율: **9.6% (70,764 / 677,085)**
* 2023.7 이후, **가입자 < 탈퇴자**인 달 다수 발생
* **탈퇴 사유**:

  * 기타: 56.95%
  * 함께할 친구 없음: 20.42%
  * 질문 콘텐츠 부족: 18.56%

### (2) 투표 참여율 저조

* 전체 유저 대비 투표 경험자 비율: **0.716%**
* 전체 유저 대비 투표 대상자 비율: **2.278%**

➡️ 가입만 하고 **비활성화되는 유저 다수** 존재

## 4. 분석 내용

### (1) 친구 수와 활동성 관계

* **친구 수 ↑ → 투표, 포인트 사용, 구매 등 모든 활동지표 ↑**
* Kruskal-Wallis 검정: 모든 지표에서 유의한 차이 (p < 0.05)
* **하위 25% (평균 친구 19명) → 상위 25% (평균 친구 96명) 시 투표 4.6배 증가**

### (2) 질문 카테고리 분석 (3,900개 질문)

* **카테고리**: 외모, 성격, 능력, 연애, 취미, 기타
* **특징 요약**:

  * 능력: 참여 폭발형 (포인트 획득↑, 소모↓)
  * 연애: 프리미엄형 (참여↓, 포인트 소모↑)
  * 성격: 밸런스형 (참여 & 지불 모두↑)
  * 기타: 노잼형 (참여율↓)

### (3) 유저 군집 분석 (클러스터링)

* Cluster0 (휴면): 활동 거의 없음
* Cluster1 (슈퍼 유저, 0.6%): 투표·포인트 사용 최상위
* Cluster2 (소셜 유저, 31%): 친구 많음·출석 높음, **투표 적음**
* Cluster3 (관리대상): 밴 비율 높음

➡️ **소셜 유저(Cluster2)**: 투표만 활성화되면 바로 슈퍼 유저로 전환 가능

## 5. 해결 방안

### 1) 친구 네트워크 확장 전략

* **대상**: 친구수 하위 25% (172,210명)
* **액션**:

  * 신규 온보딩 미션: 가입 7일 내 친구 32명 달성 → 포인트 보상
  * 저친구 유저 대상 “친구 초대 이벤트” 푸시 (인스타/카톡 연동)
* **기대효과**: 활동성 2.5배 증가

### 2) 질문 카테고리별 차별화 전략

* 능력: 질문 25% 확대 (신규 유저 유입)
* 연애: 프리미엄 이벤트화 (발렌타인데이, 크리스마스)
* 성격: 고효율 질문 위주 집중 노출
* 기타: 하위 30% 제거/재분류

➡️ **참여율 상승 + 포인트 소모 증가 → 매출 향상**

### 3) 소셜 유저 투표 활성화 전략

* **대상**: Cluster2 소셜 유저 (31%, 101,835명)
* **액션**:

  * “친구가 참여 중인 투표” 홈피드 최상단 노출 (A/B 테스트)
  * 투표 결과 기반 “나의 이미지 카드” 생성 → 인스타 공유
* **기대효과**: 투표 참여율 30% ↑ → 전체 투표량 대폭 증가

## 📌 결론

* **친구 네트워크 강화 + 질문 콘텐츠 최적화 + 소셜 유저 활성화** → 투표 참여율 및 포인트 사용 증가
* **단기 효과**: 참여율 회복, 포인트 매출 증가
* **장기 효과**: 유저 정착률 향상, 서비스 수익 구조 안정화
